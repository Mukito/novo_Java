## Documentação do Java
A documentação oficial do Java é um recurso essencial para desenvolvedores que desejam aprender, consultar APIs ou explorar exemplos de código. Aqui estão algumas opções para acessá-la:


### 1. Documentação Oficial da Oracle
A Oracle fornece a documentação completa do Java SE (Standard Edition), incluindo tutoriais, guias de API, exemplos e muito mais. Você pode acessá-la no site oficial:
***Documentação Java SE*** - Oracle  - https://docs.oracle.com/en/java/


### 2. Comunidades e Fóruns em Português
Se você prefere materiais em português, fóruns como o GUJ e Alura oferecem discussões, dicas e links úteis para a documentação oficial e não oficial:
  * GUJ - Documentação Java em Português - https://www.guj.com.br/t/documentacao-java-em-portugues/377706
  * Fórum Alura - Onde fica a documentação Java? - https://cursos.alura.com.br/forum/topico-onde-fica-a-documentacao-java-322134



Esses recursos são ótimos para aprender e resolver dúvidas sobre o desenvolvimento em Java. Se precisar de algo mais específico, é só pedir! 😊
