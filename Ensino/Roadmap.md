# Particularidades da Linguagem

### 🚀 Roadmap Java → API REST

**1 - Fundamentos do Java**
  * Sintaxe básica (classes, objetos, métodos, public static void main)
  * Tipos de dados e variáveis
  * Estruturas de controle (if, for, while, switch)
  * Orientação a Objetos (POO): herança, polimorfismo, interfaces, abstração

**2 - Java Intermediário**
  * Collections API (List, Set, Map)
  * Generics
  * Exceptions (try/catch, throws)
  * Streams e Lambdas
  * Manipulação de arquivos e I/O

**3 - Ferramentas de Desenvolvimento**
  * JDK + IDE (IntelliJ, Eclipse ou VS Code com extensão)
  * Gerenciador de dependências (Maven ou Gradle)
  * Testes unitários (JUnit)

**4 - Banco de Dados com Java**
  * JDBC (conceito)
  * JPA/Hibernate (ORM → mapeamento objeto-relacional)

**5 - Spring Framework / Spring Boot**
  * Inversão de Controle e Injeção de Dependência
  * Criação de projetos com Spring Boot (start.spring.io)
  * Controllers, Services, Repositories
  * REST API (GET, POST, PUT, DELETE)
  * Validação e tratamento de erros
  * Spring Data JPA (conexão com banco)
  * Segurança básica (Spring Security + JWT)

**6 - Boas Práticas**
  * Padrões de projeto (DAO, DTO, Singleton, Factory)
  * Documentação de API (Swagger/OpenAPI)
  * Testes de integração
  * Deploy (Docker, serviços em nuvem)
