# Node

é uma plataforma de desenvolvimento de software construída sobre o motor de execução JavaScript V8, 
desenvolvido pelo Google para o Chrome. A principal função do Node.js é permitir que desenvolvedores usem JavaScript, 
uma linguagem tradicionalmente usada apenas no lado do cliente (navegador), também no lado do servidor, 
para criar aplicações de rede e servidor. 

Desta forma, o Node.js é uma tecnologia open-source e multiplataforma, que possibilita o desenvolvimento de 
aplicações escaláveis com uma arquitetura orientada a eventos e baseada em um modelo assíncrono, 
o que o torna extremamente eficiente para aplicações em tempo real e manipulação de grandes volumes de dados. 

Ele oferece uma experiência de desenvolvimento ágil e eficiente, usando um único conjunto de ferramentas para backend e frontend, 
promovendo um código mais coeso.
